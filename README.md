# 浮窗看图器（FloatingImageViewer）

无边框、透明、置顶的全屏浮窗看图器（WPF，.NET 10）。支持多图层叠加、GIF 逐帧播放、框选马赛克编辑、系统托盘驻留。

## 功能一览

- **多图层系统**：一次可叠加任意多张图片，每张图是独立图层，拥有独立的缩放/平移/显隐/层叠顺序，互不干扰
- **悬停即选中**：鼠标移到哪张图上，滚轮缩放、中键平移、双击切换就直接作用于该图层，无需先点击
- **GIF 逐帧播放**：每个 GIF 图层拥有独立播放器，同时打开多个 GIF 各自播放；"暂停GIF动画"为总控
- **框选马赛克**：进入编辑模式后全屏任意位置框选区域，实时应用马赛克 / 高斯模糊 / 噪声 / 纯色遮挡
- **缩放**：滚轮以指针为锚点缩放，步进按图片分辨率自适应（小图放大快、大图缩小快），双击切换「适配窗口 / 原始大小」，中键拖拽平移，图片拖出屏幕自动回中心
- **背景模式**：完全透明（透出桌面）/ 黑色 / 白色 / Alpha 棋盘格，只覆盖活动图层区域
- **系统托盘**：任务栏不显示图标，程序图标驻留托盘（左键激活窗口，右键菜单与窗口右键一致）
- **渲染优化**：解码缓存（LRU）、超大图降采样、交互期间低质量采样保证跟手、棋盘格纹样屏幕恒定
- **位置持久化**：图片位置、缩放模式、背景、不透明度等设置自动保存恢复

## 鼠标操作

| 操作 | 功能 |
| --- | --- |
| 左键拖拽 | 移动鼠标下的图层（悬停即选中；平移由左键承担，中键不再负责拖拽） |
| 滚轮 | 以指针为锚点缩放（步进按图片分辨率自适应） |
| 双击 | 切换「适配窗口 / 原始大小」 |
| 中键单击（鼠标在图片上） | 删除该图层（多图时；单图不删防误触退出）；马赛克模式下擦除马赛克 |
| Shift + 中键单击（鼠标在内容上） | 一键删除所有马赛克与图层（仅保留第一张） |
| 右键 | 弹出菜单（窗口或托盘均相同） |

## 剪贴板监听

- 右键菜单 **剪贴板监听**（勾选，默认关闭，**状态持久化**）：开启后，复制图片会自动粘贴到屏幕上成为新图层（名为"剪贴板图片"）
- **支持两种复制来源**：任意应用的图像数据（截图/图片 Ctrl+C），以及**文件资源管理器中复制的图片文件**（多选复制也支持）
- **多图粘贴**：一次复制多张图片时，按"窗口重叠"样式依次向右下错位层叠（每张偏移 32px）
- 自动粘贴的内容缩放限制为**不超过屏幕宽/高的 75%**（原始小图不放大）
- 去重：内容指纹（尺寸 + 采样像素）/ 文件指纹，同一内容不重复添加；监听开启前已有的复制不粘贴；对比/马赛克模式下自动暂停监听

## 图片对比模式

- 右键菜单 **图片对比 → 选择对比图片...**：A = 当前图，B = 所选图，进入对比模式（清空图层）
- **左右并排 / 上下并列**：两张图贴在一起（8px 间距）整体居中
- **滑动分割**：两张图同一视图叠加，拖动中间的蓝色分割线左右切换显示（分割线只覆盖图片范围）
- **适应大小**（勾选）：左右并排时两图等高、上下并列时两图等宽（取较大者按比例），适合高/低分辨率图对比
- 初始缩放保持 A 图进入前的缩放（不放大）；滚轮同步缩放两图，左键/中键拖拽同步平移
- 支持 GIF 对比（各自独立播放）；对比中可重新选择对比图片；右键菜单 **图片对比 → 退出对比** 恢复当前图片

## 多图层系统

- 右键菜单 **添加图片...**：支持多选一次性添加多张图片，每张成为独立图层（依次置顶）
- **图层** 子菜单：图层列表（▶ 标记活动层，勾选 = 显示/隐藏，点击即选中）、上移/下移（≥2 张时显示）、删除图层
- 删除图层后自动选中相邻图层；**只剩一张图时删除等同退出程序**
- GIF 图层各自独立播放，添加静图不影响其他 GIF 播放

## 框选马赛克

1. 右键菜单 **框选马赛克 → 开始框选**：当前画面渲染为内存取样底图并清空图层，进入绘制模式
2. 左键拖拽框选区域，蓝色虚线框内**实时预览**效果，松手固定，可连续框选多个区域
3. 样式与参数（均在菜单内自定义）：
   - **马赛克**：块大小 8/16/32/64 px 或自定义（2–200）
   - **高斯模糊**：模糊像素 4/8/16/32 或自定义（1–100）
   - **噪声**：偏移像素 4/8/16/32 或自定义（1–100）
   - **纯色**：8 种预设色 + 自定义系统色盘
4. **效果固定在图片（底图）图层上**：图片如何缩放/平移，马赛克就如何跟随移动，不覆盖屏幕
5. 中键单击擦除单块马赛克；**右键直接退出绘制模式**（效果保留，不弹菜单）

## 背景与渲染

- 背景（黑/白/棋盘格）只覆盖活动图层区域，窗口其余部分透明透出桌面
- 棋盘格纹样在屏幕上保持恒定大小（不随图片缩放）
- 交互期间临时低质量采样保证跟手，停止后自动恢复
- 大图解码按 LRU 缓存（图片缓存菜单可配置），16K 以上大图自动降采样

## 无用小功能

- **抗锯齿**（装饰性）：模式 关闭 / SSAA / MSAA / TXAA，各带参数预设（SSAA 倍率 2x/4x/8x、MSAA 采样 2x/4x/8x、TXAA 质量 低/中/高）。
- 注意：窗口为透明分层窗口走软件渲染，WPF 软件渲染器不执行像素着色器，抗锯齿为映射到位图缩放采样质量的近似效果。

## 系统托盘

- 窗口保持显示，但任务栏不显示图标；程序图标驻留系统托盘
- 托盘左键：激活窗口；托盘右键：与窗口右键完全相同的菜单
- 退出程序（含托盘菜单）时自动清理托盘图标

## 会话恢复

- 退出时保存窗口内**所有图层**（路径、缩放、位置、显隐），下次启动**自动恢复**，无需重新选图
- 恢复解码走 LRU 解码缓存（命中即秒开）；有历史会话时跳过文件选择器
- 单个图层文件丢失/被移动时自动跳过，不影响其余图层恢复

## 设置与数据

- 设置保存在 `%APPDATA%\FloatingImageViewer\settings.json`（可用环境变量 `YELEE_IMGVIEWER_DATA_DIR` 重定向）
- 原子写入 + 损坏自动回退默认值；下次启动恢复全部状态

## 构建 / 发布

```powershell
dotnet publish FloatingImageViewer\FloatingImageViewer.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=None -p:DebugSymbols=false -o publish\FloatingImageViewer
```

运行 `publish\FloatingImageViewer\FloatingImageViewer.exe`，或在工具箱（YeLeeToolbox）中「即兴添加」该 exe 一键调用。
